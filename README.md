# asahi-a

Rebuild my Fedora Asahi Remix 44 (GNOME) system from the official **Minimal** image with one command.
Public repo: no secrets and no home files in here. Personal data, keys and configs live in a `<date>_asahi_home_full.tar.zst` archive on an external drive.

## Restore
1. Install Fedora Asahi Remix 44 **Minimal** from macOS with the Asahi installer, create user `blank`, boot, log in, connect to the network, plug in the drive.
2. Run:
   ```
   curl -fsSL https://raw.githubusercontent.com/memory-colors/asahi-a/main/bootstrap.sh | sudo bash
   ```
   It clones this repo to `/root/asahi-a` and runs `rebuild.sh`. Every phase asks first; `dnf` shows its own prompts (no `-y`).
3. Reboot, then `sudo /root/asahi-a/rebuild.sh verify`.

Useful: `sudo ./rebuild.sh packages` (one phase), `--dry-run` (print, change nothing), `--archive FILE` (skip the archive menu).

| phase | does |
|---|---|
| repos | rpm macro so new packages skip non-English locales, RPM Fusion release, custom `.repo` files |
| packages | `dnf install --allowerasing` the explicit packages, then removes leftover Minimal packages after a capability-level dependency check |
| files | system files (`files/system` mirrors `/`), reboot-picker, GNOME settings (`files/dconf-user.ini`), SELinux relabel |
| services | enable/disable units from `lists.txt`, default target graphical |
| apps | LosslessCut and czkawka-gui from GitHub releases |
| archive | lists every `*_asahi_home_full.tar.zst` on mounted drives (or offers to mount one), you pick a letter, it unpacks over `/` |
| verify | read-only diff of installed packages and units against `lists.txt` |

Deliberately NOT automated: bleachbit locale cleanup, initramfs/plymouth rebuild (`dracut`), bootloader changes, Claude Code install, partitioning.

## Backup (on the source system)
`./rebuild.sh publish` (or the "Backup" launcher), as the normal user, with `--dry-run` to rehearse:
1. one archive of the home folder (plus Wi-Fi/Mullvad/icon themes) onto `<drive>/Software`, read back to verify
2. installer files to GitHub (secrets scan, asks before pushing), verify
3. cleanup of this run's leftovers (asks)
4. `<date>_asahi_restore_README.txt` next to the archive

What is excluded from the archive: `ARCHIVE_EXCLUDES` at the top of `rebuild.sh`. The archive is unencrypted: keep it on the drive only.

## Layout
- `lists.txt` - `[install] [remove] [enable] [disable] [closure]` (closure = full package list of the recorded system), regenerated by `publish`
- `files/system/` - non-RPM system files; `files/Software/asahi_atomic/` - reboot-picker + package baselines; `files/dconf-user.ini`
- the patched `gnome-shell-theme.gresource` is only restored on gnome-shell 50.5; on other builds the stock file is kept and the `machine-setup` color scripts must be re-run
